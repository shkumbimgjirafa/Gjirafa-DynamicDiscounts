# Failure and unusual cases (plan section 6, Sun 13:00–14:30)

Each case the plan names, what the system does, and the test that proves it (`dotnet test`, 1,040 passed, 1 skipped:
the opt-in real headless call). Tests run on scripted Claude Code answers and in-memory or LocalDB sandbox data; injected
rows and runs are labelled `[INJECTED-TEST]` and live in the test database `PricingToolHackathonTest`.

Also unusual and handled: dead stock under the floor is its own lane (`CostWatcherTests.Prices_another_rule_owns…`,
`RunCheckRulesTests.Dead_stock_may_go_below_cost_down_to_its_40_percent_hard_floor`), GjirafaMall prices that follow
Gjirafa50 are left to Gjirafa50 (`CostWatcherTests.A_mall_price_that_follows_gjirafa50_is_left_to_gjirafa50`), a price at or
above the shelf price is never written as a discount, a failure in the middle of a publish chunk rolls back only that chunk.
